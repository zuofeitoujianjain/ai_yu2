# aiyu 功能规划（Roadmap）

> 版本：v1（依据项目现状与需求梳理）
> 说明：难度为粗略评估（低/中/高）；带 🎯 的是**priority 先做**项。
> 落地一个功能后，在「✅ 已完成」处登记，并从「Todo」移除。

---

## 🎯 近期优先（先做 3 个，性价比最高）

| 优先级 | 功能 | 说明 | 难度 |
| --- | --- | --- | --- |
| 🎯 1 | **关键词触发** | **首次 @ 启动对话后，后续回复不用再 @；命中关键词（如"鱼"）自动回** | 低 |
| 🎯 2 | **指令系统** | `/help`、`/人设 高冷`、`/开关 图片`、`/群设置` 等斜杠命令 | 低 |
| 🎯 3 | **工具调用 / Agent 化** | 给模型开放 tool（联网搜索、翻译、天气、查资料），AI 自己决定调哪个 | 中 |

> 补充：**Web 管理面板**（查看日志、改人设、开关功能、统计消息量/token 成本、群白名单）也很有价值，作为中期重点。

## 🧠 一、AI 能力进阶（最容易出彩、适合简历）

| 功能 | 说明 | 难度 |
| --- | --- | --- |
| 图片理解 | @它并带图，让 AI 看图回答。**模型：deepseek-v4-flash-vision-exp**（平时主对话用 v4-flash-low） | 中 |
| 工具调用 / Agent 化 | 给模型开放 tool（联网搜索、翻译、天气、查资料），AI 自己决定调哪个 | 中 |
| 智能路由 | 简单问题走快速模型，复杂/推理题自动切到 **v4-flash-high 思考模型** | 低 |

## 💬 二、交互体验（高频、用户感受最直接）

| 功能 | 说明 | 难度 |
| --- | --- | --- |
| 关键词触发 | **首次 @ 后，后续对话不用再 @；命中关键词（如"鱼"）就自动回** | 低 |
| 指令系统 | `/help`、`/人设 高冷`、`/开关 图片`、`/群设置` 等斜杠命令 | 低 |

## 🗄️ 三、记忆与群体管理（拉开差距）

## ✅ 已完成

| 功能 | 说明 |
| --- | --- |
| @ 触发 | 识别 @机器人，只取 @ 后的文本 |
| 双格式解析 | 兼容 CQ 码字符串 / 消息段数组 |
| 私聊 | 可直接私聊（可开关） |
| 独立会话记忆 | 按群 + 人维护最近 N 轮 |
| 清空记忆 | 关键词触发重置 |
| 长回复拆分 | 超长自动拆条 |
| 断线重连 | 指数退避自动重连 |
| 一键启动/停止 | Windows 双击、端口级精准进程管理 |
| 迁移包 | 免安装跨机部署 |
| 测速脚本 | speedtest.py 定位性能瓶颈 |
| 关键词触发 | 命中 `trigger_keywords` 即回发送者并进入免@窗口 |
| 免@对话 | @过机器人后该用户在该群免@（按用户，带窗口时长） |
| 限流冷却 | 每用户冷却秒数，超频静默忽略 |
| 指令系统 | `/help` `/人设` `/画像` `/开关` 等斜杠命令 |
| 多角色/多群独立人设 | 每群可通过 `/人设 <名>` 切换不同人格 |
| 用户画像 | 记录群名片与常用话题（bigram 统计），对话时注入资料卡 |
| 智能路由 | 简单问题走 deepseek-chat，复杂/推理自动切 deepseek-reasoner |
| 工具调用（免密钥） | 时间 / 天气(open-meteo) / 翻译 / 计算，Agent 化自动调用 |
| 长期记忆 | `memory.json` 持久化 + bigram 相似度召回，跨会话/重启记住前因后果 |
| 黑白名单权限 | allowed/blocked 群+用户过滤，白名单优先，管理员绕过限制 |
| 掉线/报错告警 | 连接断开 / DeepSeek 接口报错，自动私聊管理员（限流防刷） |
| Web 管理面板 | 进程内 aiohttp + token，127.0.0.1 访问，可看日志/状态/开关/人设/白名单 |
